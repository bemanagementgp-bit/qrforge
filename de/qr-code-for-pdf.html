QR-Code für ein PDF: So funktioniert es

  
Ein QR-Code kann kein PDF enthalten; selbst eine einseitige Datei ist viel zu groß für das Muster. Was er kann, ist einen Link zu einem online gehosteten PDF öffnen – und genau das willst du: Die Broschüre, das Handbuch, das Datenblatt oder die Preisliste öffnet sich auf dem Smartphone, sobald jemand scannt. Die eigentliche Arbeit besteht darin, die Datei an einem stabilen Ort zu hosten und einen Link zu bekommen, der das Dokument direkt öffnet.
QRForge erzeugt den Code dann kostenlos in deinem Browser, in deinen Farben, als druckfertiges PNG oder SVG.

  
Das PDF hosten und einen direkten Link bekommen

  
Wähle einen Hoster, den es in zwei Jahren noch gibt, und stell die Freigabe so ein, dass alle mit dem Link das Dokument ansehen können:
  • Deine eigene Website – lade das PDF hoch und verlinke es (deinedomain.de/files/broschuere.pdf). Die zuverlässigste Option und die kürzeste URL.
  • Google Drive – Rechtsklick auf die Datei, Teilen, auf „Jeder mit dem Link“ stellen, Link kopieren. Betrachter sehen sie im Drive-Viewer, der auf jedem Smartphone funktioniert.
  • Dropbox – erstelle einen Freigabelink; ändere das abschließende dl=0 zu dl=1, wenn die Datei heruntergeladen statt angezeigt werden soll.
  • OneDrive, Box, Notion – funktionieren alle mit einem öffentlichen Freigabelink.
Öffne den Link in einem privaten Browserfenster, um sicherzugehen, dass er ohne Anmeldung lädt. Füge ihn dann im Tab URL ein. Links von Drive und Dropbox sind lang und ergeben einen dichten Code; wenn du eine Domain hast, erstelle eine kurze Weiterleitung (deinedomain.de/handbuch) und kodiere stattdessen diese.

  
Damit der Code funktioniert, wenn sich das PDF ändert

  
Da der Code statisch ist, verweist er auf die URL, nicht auf die Datei. Überschreibe auf deiner eigenen Website das PDF mit der neuen Version unter demselben Dateinamen, und jeder gedruckte Code öffnet weiterhin das neueste Dokument. Klicke in Google Drive mit der rechten Maustaste auf die Datei und wähle „Versionen verwalten“, um eine neue Version mit demselben Link hochzuladen; eine neue Datei hochzuladen erzeugt einen neuen Link und macht gedruckte Codes unbrauchbar.
Halte das PDF klein (unter 3–5 MB), damit es mit mobilen Daten schnell öffnet, und mach die erste Seite auf einem Smartphone-Bildschirm nützlich. Beim Druck reicht ein 3-cm-Code auf einem Flyer oder Produktetikett; Poster und Schilder, die aus der Entfernung gescannt werden, sollten 8 cm oder mehr haben. Füge eine Beschriftung hinzu, die sagt, was das PDF ist („Scannen für alle technischen Daten“), und gib die Kurz-URL als Text zur Sicherheit an.

  
Häufig gestellte Fragen

  

    
Kann ein QR-Code das PDF selbst speichern?
Nein. Ein QR-Code fasst höchstens etwa 3 KB Text, während selbst ein winziges PDF viel größer ist. Der Code speichert den Link zum PDF, das online gehostet sein muss.

    
Warum verlangt mein Google-Drive-Link eine Anmeldung?
Die Freigabe der Datei ist eingeschränkt. Öffne Teilen, stell den allgemeinen Zugriff auf „Jeder mit dem Link“ mit Leserechten und teste den Link in einem privaten Fenster, bevor du den Code erzeugst.

    
Kann ich das PDF aktualisieren, nachdem der QR-Code gedruckt ist?
Ja, wenn du die Datei unter derselben URL ersetzt. Überschreibe sie auf deiner Website oder nutze „Versionen verwalten“ in Google Drive. Ein neuer Upload mit neuem Link funktioniert nicht mit vorhandenen Codes.

    
Wird das PDF zu QRForge hochgeladen?
Nein. QRForge kodiert nur den Link, den du einfügst. Die Datei bleibt dort, wo du sie hostest, und der Code wird in deinem Browser erzeugt.
