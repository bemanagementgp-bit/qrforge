Código QR para el menú de un restaurante: cómo funciona

  
La mayoría de los servicios de "QR para menú" cobran una suscripción y hacen pasar cada escaneo por sus servidores; cuando dejas de pagar, los códigos de tus mesas dejan de funcionar. Un código QR estático de QRForge apunta directamente a la URL de tu menú. Es gratis, funciona mientras la página exista y nadie se interpone entre tu cliente y tu menú.
Genéralo en el navegador, combina los colores con tu marca y descarga un PNG para carteles de mesa, stickers para vitrina y el frente de la carta.

  
Configura el enlace del menú antes de crear el código

  
El código QR solo es tan bueno como la página que abre, así que primero asegúrate de que el destino sea el correcto:
  • Usa una URL que controles – una página en tu propio sitio web (turestaurante.com/menu) o un enlace estable de tu plataforma de pedidos. Evita enlazar a un archivo en una app de chat o en un Drive personal que podría reorganizarse.
  • Piensa primero en el celular – una página web es mejor que un PDF. Si tienes que usar un PDF, que pese menos de 2 MB y esté en vertical, para que se lea en el teléfono sin hacer zoom.
  • Mantén la URL corta – las URL más cortas generan un código más simple que se escanea más rápido. Si la URL de tu menú es larga, crea una redirección corta en tu propio dominio.
  • Planifica las actualizaciones – como el código es estático, cambia el menú en la página, no el enlace. El código sigue funcionando.
Pega la URL definitiva en la pestaña URL con https:// incluido y luego escanea la vista previa con tu teléfono para comprobar que abre la página correcta.

  
Cómo imprimirlo para mesas, vitrinas y pedidos para llevar

  
Un cartel de mesa se escanea desde 30–50 cm, así que un código de 3 cm alcanza; un cartel en la vitrina o en la acera que se escanea desde la calle necesita 8–10 cm o más. Exporta a 1000 px para impresiones pequeñas, o usa SVG (incluido en la mejora Pro de pago único) cuando la imprenta pida un vector.
Mantén el código oscuro sobre un fondo claro. Los colores de marca están bien si el contraste sigue siendo alto; un código dorado sobre crema frustrará a tus clientes. Deja el margen de la zona de silencio en el valor predeterminado y nunca imprimas el código sobre una foto o papel con textura. Agrega un texto corto al lado, "Escanea para ver el menú", y la URL en texto para quienes tengan la cámara desactivada.
Plastifica las copias de las mesas; un código rayado o manchado se sigue escaneando gracias a la corrección de errores, pero uno muy gastado terminará por no funcionar.

  
Preguntas frecuentes

  

    
¿El código QR del menú vence o requiere una suscripción?
No. Los códigos de QRForge son estáticos: la URL está codificada en el propio patrón, así que el código funciona mientras la página de tu menú esté en línea. No hay nada que renovar.

    
¿Puedo actualizar el menú sin volver a imprimir los códigos?
Sí, siempre que cambies el contenido en la misma URL. Edita la página o reemplaza el PDF en la misma dirección y los códigos existentes lo seguirán abriendo.

    
¿Podemos poner nuestro logo en el centro del código?
Sí. El logo central superpuesto es una función Pro; sube la corrección de errores a H automáticamente para que el código se siga escaneando con el logo tapando una parte.

    
¿Puedo ver cuántas personas escanearon el menú?
No desde el código en sí, ya que ningún escaneo pasa por QRForge. Si necesitas contarlos, haz que el código apunte a un enlace corto con estadísticas en tu propio dominio.
