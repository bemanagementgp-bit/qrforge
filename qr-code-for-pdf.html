QR Code for a PDF: how it works

  
A QR code cannot contain a PDF; even a one-page file is far too large for the pattern. What it can do is open a link to a PDF hosted online, which is exactly what you want: the brochure, manual, spec sheet or price list opens on the phone the moment someone scans. The real work is hosting the file somewhere stable and getting a link that opens the document directly.
QRForge then generates the code free in your browser, in your colours, as a PNG or SVG ready for print.

  
Hosting the PDF and getting a direct link

  
Choose a host that will still be there in two years, then set sharing so anyone with the link can view:
  • Your own website – upload the PDF and link to it (yourdomain.com/files/brochure.pdf). The most reliable option and the shortest URL.
  • Google Drive – right-click the file, Share, set to "Anyone with the link", copy the link. Viewers see it in Drive's viewer, which works on any phone.
  • Dropbox – create a share link; change the final dl=0 to dl=1 if you want it to download rather than preview.
  • OneDrive, Box, Notion – all work with a public share link.
Open the link in a private browser window to make sure it loads without signing in. Then paste it into the URL tab. Drive and Dropbox links are long and make a dense code; if you have a domain, create a short redirect (yourdomain.com/manual) and encode that instead.

  
Keeping the code working when the PDF changes

  
Because the code is static, it points at the URL, not the file. On your own site, overwrite the PDF with the new version under the same filename and every printed code keeps opening the latest document. In Google Drive, right-click the file and choose "Manage versions" to upload a new version with the same link; uploading a new file creates a new link and breaks printed codes.
Keep the PDF small (under 3–5 MB) so it opens quickly on mobile data, and make the first page useful on a phone screen. For printing, a 3 cm code is fine on a flyer or product label; posters and signs scanned from a distance should be 8 cm or more. Add a caption telling people what the PDF is ("Scan for full specifications") and include the short URL in text as a fallback.

  
Frequently asked questions

  

    
Can a QR code store the PDF itself?
No. A QR code holds at most about 3 KB of text, while even a tiny PDF is far larger. The code stores the link to the PDF, which must be hosted online.

    
Why does my Google Drive link ask people to sign in?
The file's sharing is restricted. Open Share, change General access to "Anyone with the link" with Viewer rights, and test the link in a private window before generating the code.

    
Can I update the PDF after printing the QR code?
Yes, if you replace the file at the same URL. Overwrite it on your site, or use Google Drive's Manage versions. A new upload with a new link will not work with existing codes.

    
Is the PDF uploaded to QRForge?
No. QRForge only encodes the link you paste. The file stays wherever you host it and the code is generated in your browser.
