QR code para cardápio de restaurante: como funciona

  
A maioria dos serviços de "QR code para cardápio" cobra assinatura e passa cada leitura pelos servidores deles; quando você para de pagar, os códigos das suas mesas param de funcionar. Um QR code estático do QRForge aponta direto para a URL do seu cardápio. É grátis, funciona enquanto a página existir e ninguém fica entre o seu cliente e o seu cardápio.
Gere no navegador, combine as cores com a sua marca e baixe um PNG para displays de mesa, adesivos de vitrine e a frente do quadro de cardápio.

  
Configure o link do cardápio antes de criar o código

  
O QR code só é tão bom quanto a página que ele abre, então acerte primeiro o destino:
  • Use uma URL que você controla – uma página do seu próprio site (seurestaurante.com/cardapio) ou um link estável da sua plataforma de pedidos. Evite apontar para um arquivo em um app de mensagens ou em um Drive pessoal que pode ser reorganizado.
  • Pense primeiro no celular – uma página web é melhor que um PDF. Se precisar usar PDF, mantenha-o abaixo de 2 MB e na vertical, para ser lido no celular sem precisar dar zoom.
  • Mantenha a URL curta – URLs mais curtas geram um código mais simples e mais rápido de ler. Se a URL do seu cardápio for longa, crie um redirecionamento curto no seu próprio domínio.
  • Planeje as atualizações – como o código é estático, mude o cardápio na página, não o link. O código continua funcionando.
Cole a URL final na aba URL com https:// incluído e escaneie a prévia com seu celular para conferir se abre a página certa.

  
Imprimindo para mesas, vitrines e delivery

  
Um display de mesa é escaneado a 30–50 cm de distância, então um código de 3 cm basta; uma placa de vitrine ou cavalete escaneada da calçada pede 8–10 cm ou mais. Exporte em 1000 px para impressões pequenas ou use SVG (parte do upgrade Pro de pagamento único) quando a gráfica pedir vetor.
Mantenha o código escuro sobre fundo claro. Cores da marca funcionam se o contraste continuar alto; um código dourado sobre creme vai frustrar os clientes. Deixe a margem da zona de silêncio no padrão e nunca imprima o código sobre uma foto ou papel texturizado. Adicione uma legenda curta ao lado, "Escaneie para ver o cardápio", mais a URL em texto para quem estiver com a câmera desativada.
Plastifique as cópias das mesas; um código riscado ou manchado ainda é lido graças à correção de erros, mas um desgastado uma hora deixa de funcionar.

  
Perguntas frequentes

  

    
O QR code do cardápio vai expirar ou exigir assinatura?
Não. Os códigos do QRForge são estáticos: a URL fica codificada no próprio padrão, então o código funciona enquanto a página do seu cardápio estiver online. Não há nada para renovar.

    
Posso atualizar o cardápio sem reimprimir os códigos?
Sim, desde que você altere o conteúdo na mesma URL. Edite a página ou substitua o PDF no mesmo endereço e os códigos existentes continuam abrindo.

    
Posso colocar nosso logo no meio do código?
Sim. O logo central sobreposto é um recurso Pro; ele aumenta a correção de erros para H automaticamente para o código continuar legível com o logo cobrindo parte dele.

    
Posso ver quantas pessoas escanearam o cardápio?
Não pelo código em si, já que nenhuma leitura passa pelo QRForge. Aponte o código para um link curto com estatísticas no seu próprio domínio se precisar das contagens.
