Qu'est-ce qu'un code QR et comment fonctionne-t-il ?

    
Un code QR (Quick Response) est un code-barres en deux dimensions qui stocke du texte sous forme de grille de carrés sombres et clairs appelés modules. Les trois grands carrés dans les coins sont des motifs de repérage qui indiquent à l'appareil photo où se trouve le code et comment il est orienté ; les lignes alternées entre eux sont des motifs de synchronisation qui aident à mesurer la grille. Tout le reste correspond aux données et aux informations de correction d'erreurs. Un code QR standard peut contenir jusqu'à 4 296 caractères alphanumériques, mais en pratique un contenu plus court produit un motif moins dense qui se scanne plus vite et s'imprime plus petit.

    
La correction d'erreurs expliquée

    
Les codes QR contiennent des données Reed-Solomon redondantes pour qu'un lecteur puisse reconstituer le message même lorsqu'une partie du code est sale, déchirée ou masquée. Il existe quatre niveaux : L récupère environ 7 % des modules endommagés, M 15 %, Q 25 % et H 30 %. Les niveaux plus élevés rendent le code plus dense : M est donc le choix par défaut raisonnable dans la plupart des cas. Placer un logo au centre revient à masquer volontairement des modules, c'est pourquoi QRForge passe automatiquement au niveau H dès qu'un logo est activé.

Conseils pour un code QR qui se scanne toujours

    
Gardez un contraste élevé

    
Les lecteurs recherchent des modules foncés sur un fond clair. Du bleu marine sur blanc fonctionne ; du jaune pâle sur blanc, non. QRForge vérifie le contraste entre vos deux couleurs et vous avertit lorsqu'il est trop faible. Évitez les codes inversés (modules clairs sur fond foncé), car beaucoup d'anciennes applications photo ne peuvent pas les lire.

    
Respectez la zone de silence

    
La marge vide autour du code n'est pas décorative. La spécification demande quatre modules d'espace vide de chaque côté pour que le lecteur puisse isoler le motif des éléments graphiques environnants. Ne la réduisez que si le code est sur un fond uni sans rien autour.

    
Dimensionnez selon la distance de scan

    
Une règle pratique : le code imprimé doit mesurer au moins un dixième de la distance à laquelle il sera scanné. Un code lu à 30 cm sur une carte de visite peut faire 3 cm de large ; une affiche scannée à 2 m nécessite un code d'environ 20 cm. Les codes plus denses (texte long, correction d'erreurs élevée) demandent un peu plus de place.

    
Testez avant d'imprimer

    
Scannez le design final avec au moins deux téléphones différents, en pleine lumière et en lumière faible, une fois placé sur le support réel. Les pelliculages brillants, les surfaces courbes et les tissus se comportent tous différemment d'un écran. Imprimer une seule page de test coûte bien moins cher que de réimprimer une série de menus.


    
Codes QR statiques ou dynamiques

    
Un code QR statique encode votre contenu directement dans le motif. Il est gratuit pour toujours, n'expire jamais, fonctionne hors ligne et ne dépend de la survie d'aucune entreprise. Sa seule limite : le contenu ne peut plus être modifié après l'impression, alors faites-le pointer vers une page que vous contrôlez si vous prévoyez des mises à jour. Un code QR dynamique pointe au contraire vers une URL de redirection courte appartenant à un service ; ce service vous permet de changer la destination et compte les scans, mais facture généralement un abonnement mensuel, et le code cesse de fonctionner si l'abonnement prend fin ou si le prestataire ferme. QRForge génère uniquement des codes statiques : pas de suivi, pas de redirection et rien de stocké de notre côté.

        Les codes QR créés avec QRForge expirent-ils ?
        
Non. QRForge crée des codes QR statiques : votre contenu est encodé directement dans le motif, le code fonctionne donc pour toujours et ne dépend pas de nos serveurs. Il ne cesse de fonctionner que si la destination elle-même, comme un site web, est mise hors ligne.

      

      

        Puis-je ajouter un logo à mon code QR ?
        
Oui, avec QRForge Pro. Importez un PNG, JPG ou SVG et il est placé au centre du code sur un fond avec marge. Le niveau de correction d'erreurs passe automatiquement à H (30 % de récupération) pour que le code reste scannable malgré les modules masqués.

      

      

        Puis-je utiliser les codes QR à des fins commerciales ?
        
Oui. Chaque code QR que vous générez vous appartient et peut être utilisé à toutes fins, y compris menus, emballages, cartes de visite, affiches, publicité et produits. Aucune mention n'est requise.

      

      

        Dois-je télécharger en PNG ou en SVG ?
        
Le PNG est une image matricielle qui fonctionne partout : sites web, documents, réseaux sociaux et la plupart des impressions. Le SVG est un format vectoriel qui reste parfaitement net à toutes les tailles ; les designers et les imprimeurs le préfèrent pour les grands formats comme les banderoles et la signalétique. L'export SVG est une fonction Pro.

      

      

        QRForge suit-il les scans de mon code QR ?
        
Non. Les codes étant statiques et pointant directement vers votre contenu, aucune requête ne passe par QRForge : nous ne pouvons donc ni voir ni compter les scans. Si vous avez besoin de statistiques de scan, utilisez comme destination de votre code QR un raccourcisseur d'URL avec statistiques.
