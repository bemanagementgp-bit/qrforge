Code QR pour faire-part de mariage : comment ça marche

  
Les faire-part papier restent un moment fort, mais les cartons RSVP, les encarts de liste de mariage et les plans d'accès coûtent cher et se perdent. Un seul code QR sur le faire-part ou une carte de détails emmène les invités vers un site de mariage où ils peuvent répondre, choisir leur menu, trouver l'hôtel réservé et consulter la liste de mariage. Les aînés reçoivent toujours l'essentiel sur papier ; tous les autres scannent.
QRForge le génère gratuitement dans votre navigateur. Accordez-le à la couleur d'encre de votre papeterie, choisissez un style de points plus doux et téléchargez un PNG ou un SVG pour votre imprimeur.

  
Vers quoi pointer, et comment le configurer

  
Créez un lien vers une seule page d'accueil qui regroupe tout, plutôt que d'imprimer plusieurs codes :
  • Votre site de mariage (Zola, The Knot, Joy, un site personnel) avec la réponse RSVP, le programme, la liste de mariage et les infos pratiques. Utilisez l'URL courte du site ou un nom de domaine personnalisé si vous en avez acheté un.
  • Formulaire RSVP uniquement – un Google Form ou la page RSVP du site, si c'est la seule action que vous attendez des invités.
  • Itinéraire – un lien Google Maps vers le lieu ; utile sur la carte d'informations du jour J.
Créez le site et testez-le sur un téléphone avant de générer le code. Publiez-le avec son URL définitive, puis collez cette URL dans l'onglet URL avec https://. Si le site est protégé par un mot de passe, imprimez-le à côté du code. Créez un code simple et séparé pour le save-the-date s'il part avant que le site soit terminé, ou attendez : un code qui ouvre une page « bientôt disponible » frustre les invités.

  
L'intégrer à la papeterie

  
Accordez la couleur de premier plan à l'encre de votre faire-part : bleu marine, vert forêt, bordeaux ou anthracite se scannent bien sur une carte crème ou blanche. Évitez le doré, le rose poudré ou le vert sauge pour le code ; ils manquent de contraste. Choisissez le style de modules Points pour une touche élégante et gardez la zone de silence par défaut. Un petit monogramme au centre (fonction Pro) l'intègre à l'ensemble.
Placez le code sur une carte de détails ou de RSVP plutôt que sur le faire-part principal, en 2–2,5 cm, avec une mention comme « Scannez pour répondre avant le 1er août » et l'adresse du site en texte en dessous. Envoyez à votre imprimeur un SVG (Pro) ou un PNG de 1000 px ; la typographie et la dorure à chaud peuvent déformer les modules fins : pour ces techniques, imprimez le code en impression à plat ou agrandissez-le légèrement. Imprimez une épreuve et scannez-la avant le tirage complet.

  
Questions fréquentes

  

    
Le code QR doit-il aller sur le faire-part ou sur une carte séparée ?
Une carte séparée pour les détails ou le RSVP est le choix habituel ; elle garde le faire-part principal formel et laisse au code assez de place et une légende.

    
Puis-je modifier le site du mariage après l'impression des faire-part ?
Oui, tant que l'URL reste la même. Mettez à jour la date limite de RSVP, le programme ou la liste de mariage sur le site et le code imprimé continue de fonctionner.

    
Les invités âgés pourront-ils l'utiliser ?
La plupart des téléphones ouvrent les codes QR avec l'appareil photo intégré, mais indiquez toujours l'adresse du site en texte et gardez une option RSVP papier pour les invités qui le préfèrent.

    
Puis-je utiliser le même code pour le save-the-date, le faire-part et les cartes de remerciement ?
Oui. Un code statique qui pointe vers votre site de mariage fonctionne sur toute la papeterie, et vous pouvez mettre à jour le contenu du site à chaque étape.
