Code QR pour le Wi-Fi : comment ça marche

  
Lire un mot de passe de 16 caractères au dos d'un routeur est le pire moment de toute visite. Un code QR Wi-Fi encode le nom du réseau, le mot de passe et le type de sécurité dans un format que l'appareil photo des iPhone et des Android reconnaît nativement : on scanne, on touche « Rejoindre », c'est fait. Cela fonctionne pour les invités à la maison, les annonces Airbnb, les cafés, les salles d'attente et les bureaux dotés d'un réseau visiteurs.
QRForge génère le code gratuitement dans votre navigateur. Le mot de passe est encodé dans l'image sur votre appareil et n'est jamais envoyé nulle part, ce qui compte quand ce que vous encodez est justement un mot de passe.

  
Comment créer un code QR Wi-Fi qui se connecte vraiment

  
Choisissez l'onglet Wi-Fi et renseignez trois éléments exactement comme sur le routeur :
  • Nom du réseau (SSID) – sensible à la casse, espaces compris. « Famille Martin » et « famille martin » sont deux réseaux différents.
  • Mot de passe – copiez-le plutôt que de le retaper. Un seul caractère erroné produit un code qui se scanne bien mais ne se connecte pas, ce qui est plus difficile à diagnostiquer qu'un code qui ne se scanne pas.
  • Chiffrement – presque tous les routeurs récents utilisent le WPA2 ou le WPA3 ; choisissez l'option WPA. Ne choisissez WEP que pour du matériel très ancien, et Aucun pour un réseau ouvert.
Cochez Réseau masqué uniquement si vous avez désactivé la diffusion du SSID sur le routeur. Testez ensuite le code sur un iPhone et sur un téléphone Android avant de l'imprimer ; l'appareil photo natif de chacun doit proposer de rejoindre le réseau. Si votre routeur bi-bande a des noms séparés pour le 2,4 GHz et le 5 GHz, créez un code pour celui que les invités doivent utiliser.

  
Où le placer et à quelle taille l'imprimer

  
Pour un logement, une carte sur le réfrigérateur ou dans un cadre photo de la chambre d'amis suffit. Les locations de courte durée le placent généralement dans le livret d'accueil et sur un petit panneau près du routeur. Les cafés et les bureaux l'impriment au comptoir et sur des chevalets de table ; un code de 3–4 cm se scanne confortablement en position assise.
Utilisez le style de modules Arrondi ou Points et vos couleurs de marque si vous le souhaitez, mais gardez un fort contraste entre premier plan et arrière-plan et laissez la marge de zone de silence par défaut. Exportez en 600–1000 px pour une impression au format carte de visite ; le PNG reste net à cette taille.
N'oubliez pas que le code est statique. Si vous changez le mot de passe Wi-Fi, l'ancien code ne fonctionne plus et vous devez en générer et en imprimer un nouveau.

  
Questions fréquentes

  

    
Un code QR Wi-Fi fonctionne-t-il sur iPhone et Android ?
Oui. iOS 11 et versions ultérieures et Android 10 et versions ultérieures lisent les codes QR Wi-Fi avec l'appareil photo intégré et proposent de rejoindre le réseau en une touche. Les anciens téléphones Android peuvent nécessiter une application de lecture QR.

    
Est-il sûr de mettre mon mot de passe dans un code QR ?
Le mot de passe est stocké en clair dans le code : toute personne qui le scanne peut le lire. Traitez le code imprimé comme le mot de passe lui-même : parfait pour les invités, pas pour une vitrine publique. QRForge ne l'envoie jamais en ligne.

    
Puis-je créer un code QR pour un réseau Wi-Fi masqué ?
Oui. Activez l'option Réseau masqué. Le code indique au téléphone de se connecter au SSID même s'il n'est pas diffusé.

    
Pourquoi le code se scanne-t-il sans se connecter ?
Presque toujours une faute de frappe dans le SSID ou le mot de passe, ou un mauvais type de chiffrement. Vérifiez-les par rapport à l'étiquette du routeur et générez à nouveau le code.
