Code QR pour un PDF : comment ça marche

  
Un code QR ne peut pas contenir un PDF ; même un fichier d'une page est bien trop lourd pour le motif. Ce qu'il peut faire, c'est ouvrir un lien vers un PDF hébergé en ligne, et c'est exactement ce qu'il vous faut : la brochure, le manuel, la fiche technique ou la grille tarifaire s'ouvre sur le téléphone dès le scan. Le vrai travail consiste à héberger le fichier dans un endroit stable et à obtenir un lien qui ouvre directement le document.
QRForge génère ensuite le code gratuitement dans votre navigateur, à vos couleurs, en PNG ou SVG prêt pour l'impression.

  
Héberger le PDF et obtenir un lien direct

  
Choisissez un hébergeur qui existera encore dans deux ans, puis réglez le partage pour que toute personne disposant du lien puisse consulter le fichier :
  • Votre propre site web – importez le PDF et créez un lien vers lui (votredomaine.fr/fichiers/brochure.pdf). L'option la plus fiable et l'URL la plus courte.
  • Google Drive – faites un clic droit sur le fichier, Partager, réglez sur « Tous les utilisateurs disposant du lien », copiez le lien. Les visiteurs le voient dans la visionneuse Drive, qui fonctionne sur n'importe quel téléphone.
  • Dropbox – créez un lien de partage ; remplacez la fin dl=0 par dl=1 si vous voulez qu'il se télécharge au lieu de s'afficher en aperçu.
  • OneDrive, Box, Notion – fonctionnent tous avec un lien de partage public.
Ouvrez le lien dans une fenêtre de navigation privée pour vérifier qu'il se charge sans connexion. Collez-le ensuite dans l'onglet URL. Les liens Drive et Dropbox sont longs et donnent un code dense ; si vous avez un nom de domaine, créez une redirection courte (votredomaine.com/manuel) et encodez-la plutôt.

  
Garder le code fonctionnel quand le PDF change

  
Le code étant statique, il pointe vers l'URL, pas vers le fichier. Sur votre propre site, remplacez le PDF par la nouvelle version sous le même nom de fichier et chaque code imprimé ouvrira toujours le document le plus récent. Dans Google Drive, faites un clic droit sur le fichier et choisissez « Gérer les versions » pour importer une nouvelle version avec le même lien ; importer un nouveau fichier crée un nouveau lien et casse les codes imprimés.
Gardez un PDF léger (moins de 3–5 Mo) pour qu'il s'ouvre rapidement en données mobiles, et rendez la première page utile sur un écran de téléphone. Pour l'impression, un code de 3 cm convient sur un flyer ou une étiquette produit ; les affiches et panneaux scannés à distance doivent faire 8 cm ou plus. Ajoutez une légende indiquant ce qu'est le PDF (« Scannez pour la fiche technique complète ») et l'URL courte en texte comme solution de secours.

  
Questions fréquentes

  

    
Un code QR peut-il stocker le PDF lui-même ?
Non. Un code QR contient au maximum environ 3 Ko de texte, alors que même un tout petit PDF est bien plus lourd. Le code stocke le lien vers le PDF, qui doit être hébergé en ligne.

    
Pourquoi mon lien Google Drive demande-t-il aux gens de se connecter ?
Le partage du fichier est restreint. Ouvrez Partager, passez l'accès général à « Tous les utilisateurs disposant du lien » avec le rôle Lecteur, et testez le lien dans une fenêtre privée avant de générer le code.

    
Puis-je mettre à jour le PDF après avoir imprimé le code QR ?
Oui, si vous remplacez le fichier à la même URL. Écrasez-le sur votre site, ou utilisez Gérer les versions dans Google Drive. Un nouvel import avec un nouveau lien ne fonctionnera pas avec les codes existants.

    
Le PDF est-il envoyé à QRForge ?
Non. QRForge encode uniquement le lien que vous collez. Le fichier reste là où vous l'hébergez et le code est généré dans votre navigateur.
