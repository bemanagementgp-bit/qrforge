QR Code for Wedding Invitations: how it works

  
Paper invitations are still the moment, but RSVP cards, registry inserts and direction sheets add cost and get lost. One QR code on the invitation or a details card takes guests to a wedding website where they can RSVP, choose a meal, find the hotel block and see the registry. Elderly relatives still get the printed essentials; everyone else scans.
QRForge generates it free in your browser. Match the ink colour of your stationery, pick a softer dot style and download a PNG or SVG for your printer.

  
What to link, and how to set it up

  
Link to one landing page that holds everything, rather than printing several codes:
  • Your wedding website (Zola, The Knot, Joy, a personal site) with RSVP, schedule, registry and travel on it. Use the site's short URL or a custom domain if you bought one.
  • RSVP form only – a Google Form or the site's RSVP page, if that is the one action you need guests to take.
  • Directions – a Google Maps link to the venue; useful on the day-of details card.
Create the site and test it on a phone before generating the code. Publish it with the final URL, then paste that URL in the URL tab with https://. If the site is password-protected, print the password next to the code. Make a separate, plain code for the save-the-date if it goes out before the website is finished, or wait: a code that opens a "coming soon" page frustrates guests.

  
Making it look like part of the stationery

  
Match the foreground colour to your invitation ink: navy, forest green, burgundy or charcoal all scan well on cream or white card. Avoid gold, blush or sage as the code colour; they lack contrast. Choose the Dots module style for an elegant feel and keep the default quiet zone. A small monogram in the centre (Pro feature) ties it to the suite.
Place the code on a details or RSVP card rather than the main invitation, at 2–2.5 cm, with a line such as "Scan to RSVP by 1 August" and the website address in text beneath it. Send your printer an SVG (Pro) or a 1000 px PNG; letterpress and foil can distort fine modules, so for those techniques use flat print for the code or go slightly larger. Print one proof and scan it before the full run.

  
Frequently asked questions

  

    
Should the QR code go on the invitation or a separate card?
A separate details or RSVP card is the usual choice; it keeps the main invitation formal and gives the code enough space and a caption.

    
Can I change the wedding website after invitations are printed?
Yes, as long as the URL stays the same. Update the RSVP deadline, schedule or registry on the site and the printed code keeps working.

    
Will older guests be able to use it?
Most phones open QR codes with the built-in camera, but always include the website address in text and keep a printed RSVP option for guests who prefer it.

    
Can I use the same code for save-the-dates, invitations and thank-you cards?
Yes. A static code pointing to your wedding website works on every piece of stationery, and you can update the site content for each stage.
