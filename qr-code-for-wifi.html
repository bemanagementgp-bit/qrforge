QR Code for Wi-Fi: how it works

  
Reading a 16-character password off the back of a router is the worst part of visiting anyone. A Wi-Fi QR code encodes the network name, password and security type in a format that iPhone and Android cameras recognise natively: scan, tap "Join", done. It works for home guests, Airbnb listings, cafés, waiting rooms and offices with a visitor network.
QRForge generates the code in your browser for free. The password is encoded into the image on your device and never sent anywhere, which matters when the thing you are encoding is a password.

  
How to make a Wi-Fi QR code that actually connects

  
Pick the Wi-Fi tab and fill in three things exactly as the router has them:
  • Network name (SSID) – case-sensitive, including spaces. "Smith Family" and "smith family" are different networks.
  • Password – copy it rather than retyping. A single wrong character produces a code that scans fine but fails to connect, which is harder to debug than a code that does not scan.
  • Encryption – almost every modern router uses WPA2 or WPA3; choose the WPA option. Pick WEP only for very old hardware, and None for an open network.
Tick Hidden network only if you disabled SSID broadcast on the router. Then test the code on both an iPhone and an Android phone before printing it; the native camera app on each should offer to join the network. If you are on a dual-band router with separate 2.4 GHz and 5 GHz names, make a code for the one guests should use.

  
Where to put it and how big to print

  
For a home, a card on the fridge or inside a picture frame in the guest room is enough. Short-term rentals usually put it in the welcome binder and on a small sign by the router. Cafés and offices print it at the counter and on table tents; a 3–4 cm code is comfortable to scan from a seated position.
Use the Rounded or Dots module style and your brand colours if you like, but keep strong contrast between foreground and background and leave the default quiet zone margin. Export at 600–1000 px for a business-card-size print; the PNG stays sharp at that size.
Remember the code is static. If you change the Wi-Fi password, the old code stops working and you need to generate and print a new one.

  
Frequently asked questions

  

    
Does a Wi-Fi QR code work on iPhone and Android?
Yes. iOS 11 and later and Android 10 and later read Wi-Fi QR codes with the built-in camera app and offer a one-tap Join. Older Android phones may need a QR scanner app.

    
Is it safe to put my password in a QR code?
The password is stored in plain text inside the code, so anyone who scans it can read it. Treat the printed code like the password itself: fine for guests, not for a public window. QRForge never uploads it.

    
Can I make a QR code for a hidden Wi-Fi network?
Yes. Enable the Hidden network toggle. The code tells the phone to connect to the SSID even though it is not broadcast.

    
Why does the code scan but not connect?
Almost always a typo in the SSID or password, or the wrong encryption type. Re-check them against the router label and regenerate.
