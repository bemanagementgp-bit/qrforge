What is a QR code and how does it work?

    
A QR (Quick Response) code is a two-dimensional barcode that stores text as a grid of dark and light squares called modules. The three large squares in the corners are finder patterns that tell a camera where the code is and how it is rotated; the alternating lines between them are timing patterns that help measure the grid. Everything else is data and error-correction information. A standard QR code can hold up to 4,296 alphanumeric characters, although in practice shorter content produces a less dense pattern that scans faster and prints smaller.

    
Error correction explained

    
QR codes include redundant Reed-Solomon data so that a scanner can rebuild the message even when part of the code is dirty, torn or covered. There are four levels: L recovers about 7% of damaged modules, M 15%, Q 25% and H 30%. Higher levels make the code denser, so M is the sensible default for most uses. When you place a logo in the center you are deliberately covering modules, which is why QRForge switches to level H automatically whenever a logo is enabled.

Tips for a QR code that always scans

    
Keep the contrast high

    
Scanners look for dark modules on a light background. Dark navy on white works; pale yellow on white does not. QRForge checks the contrast between your two colors and warns you when it is too low. Avoid inverted codes (light modules on a dark background) because many older camera apps cannot read them.

    
Respect the quiet zone

    
The blank margin around the code is not decoration. The specification asks for four modules of empty space on every side so the scanner can isolate the pattern from surrounding graphics. Reduce it only if the code sits on a plain background with nothing nearby.

    
Size for the scanning distance

    
A useful rule of thumb is that the printed code should be at least one tenth of the distance it will be scanned from. A code read from 30 cm on a business card can be 3 cm wide; a poster scanned from 2 m needs a code around 20 cm wide. Denser codes (long text, high error correction) need a bit more room than that.

    
Test before you print

    
Scan the final design with at least two different phones, both in bright light and in dim light, after it has been placed on the real material. Glossy laminates, curved surfaces and fabric all behave differently from a screen. Printing a single test page is far cheaper than reprinting a batch of menus.


    
Static vs. dynamic QR codes

    
A static QR code encodes your content directly in the pattern. It is free forever, never expires, works offline and does not depend on any company staying in business. Its only limitation is that the content cannot be changed after printing, so link to a page you control if you expect updates. A dynamic QR code instead points to a short redirect URL owned by a service; the service lets you change the destination and counts scans, but usually charges a monthly fee, and the code stops working if the subscription ends or the provider shuts down. QRForge generates static codes only: no tracking, no redirects and nothing stored on our side.
